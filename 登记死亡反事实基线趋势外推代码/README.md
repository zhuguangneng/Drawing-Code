# 现行逐因素与七因素联合情景分析包

当前趋势版本：`trend-registration-v1.3-2016-2022-baseline`。共同基线采用2016—2022年加沙登记癌症死亡（348、474、566、548、539、777、915）及同期PCBS年中人口，拟合带人口offset的泊松率趋势，并以Pearson离散度修正系数协方差。2023年人口为2,226,544。

2023年无战争反事实登记口径共同基线为997.2例（95% UI 834.4～1189.3）；模型点预测为997.5例。五折扩展窗口回测的MAPE为20.51%。该基线不是2023年实际登记数，也没有校正战争期间漏报。

`癌症特异性死亡逐因素蒙特卡洛结果.xlsx`保留两层结果：六项新增因素的逐因素结果用于显示组件信号；七因素联合模型在A、D、H、P、E、C基础上加入前序研究的治疗延迟或中断T，并通过64种互斥组合、证据校准的重叠关系和路径覆盖规则计算综合情景。逐因素增量不得相加。

六因素逐因素增量中位数依次为：A 6.3例、D 74.9例、H 2.3例、P 47.0例、E 38.9例、C 26.1例。七因素联合主情景为1239.5例（1013.6～1519.5），相对共同基线增加239.8例（131.2～391.6），相对增加24.11%（13.48%～37.94%）。E只使用2023年10月暴露增量，列为探索性分析；C主分析排除Fair。

主要文件：

- `single_factor_monte_carlo.py`、`trend_extrapolation_monte_carlo.py`：2016—2022年趋势及六因素逐因素分析代码。
- `analysis_config.json`、`analysis_results.json`及各CSV：完整参数、结果、回测与敏感性分析。
- `癌症特异性死亡逐因素蒙特卡洛结果.xlsx`：逐因素参考结果与七因素联合主分析的整合工作簿。
- `../step2/逐因素建模参数表.xlsx`：效应证据、映射参数、趋势外推和联合模型全过程。
- `../joint_effect_model_evidence_calibrated/`：七因素联合模型代码、64种组合、条件关联证据、敏感性和独立结果工作簿。
- `../manuscript_revision/战争相关因素与加沙癌症死亡负担预测_系统综述Meta分析及情景模拟_中文整合稿.docx`：现行中文正文。
